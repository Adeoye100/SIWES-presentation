07 | TECHNICAL CHALLENGES & PROCESS

Challenges & Technical Solutions

Real engineering problems faced during development and how I solved them.

Technical Problems & Fixes
Challenge: Preventing data loss when the desktop app loses internet connection while saving data. Solution: Created local SQLite write queues that store data offline and sync to the server when reconnected.
Challenge: Managing multiple fast API requests without UI state errors or memory leaks. Solution: Used AbortController cancellation signals and structured state machine logic to drop stale responses.

08 | CRITICAL REFLECTION

Key Learnings & Self-Reflection

Core takeaways from real-world software engineering.

Reflection Q&A
Moving from just building frontend UI components to thinking about data flow, memory usage, and background persistence first.
Real-world work showed that code must handle offline modes and low-end hardware cleanly. Error handling and reliability matter just as much as writing neat functions.
It focused my career goals on systems engineering, desktop and web hybrid applications, and building reliable tools for actual users.
Core Engineering Rule
Every design choice is based on performance testing, type checking, and clear fallback plans when offline.
